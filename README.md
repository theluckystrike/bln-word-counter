# Word Counter

Free online word, character, and sentence counter with readability scoring and ESL difficulty analysis.

**[Try it live →](https://theluckystrike.github.io/bln-word-counter/)**

## Features

- Word, character, sentence, and paragraph counts
- Flesch-Kincaid readability score
- Gunning Fog index
- ESL difficulty level analysis
- Reading time estimation
- Real-time updates as you type

## Usage

Open the tool in your browser — no installation required. Paste or type your text and get instant results.

## Tech Stack

- Pure HTML, CSS, JavaScript
- No dependencies or build step
- Hosted on GitHub Pages
- Works offline after first load
